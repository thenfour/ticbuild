
ticbuild watch

usage: ticbuild watch [options] [manifest]

Build a TIC-80 cart, launch it, and watch for changes

When source files or the manifest change, the cart is automatically
rebuilt and TIC-80 is relaunched with the updated cart.

With the bundled TIC-80, watch also attaches an interactive
terminal. Pushed events such as trace and script_error are printed as they
arrive, and remoting commands can be entered directly. Request IDs are optional:

  > ping

Additional watch globs can be configured via project.additionalWatchGlobs
in the manifest.

Arguments:

  [manifest]           Path to manifest file (default: first *.ticbuild.jsonc)

Options:

  -m, --mode <name>    Build configuration name from manifest
  -v, --var <key=value> Override manifest variable (can be used multiple times)
  --env <key=value>    Override project environment value (can be used multiple times)
  --remoting-verbose   Verbose TIC-80 remoting output
  --hide-trace-containing <text> Hide trace events whose payload contains text
  --hide-trace-matching <regex>  Hide trace events whose payload matches a JavaScript regex
  --on-connect <command> Send a required remoting command after connecting
                         (can be used multiple times; runs serially before load)
  -h, --help           Show this help message

Forwarding to TIC-80:

  Use "--" to pass arguments through to TIC-80.

  Example:
    ticbuild watch -- --fs=c:\\temp --skip

Examples:

  ticbuild watch
  ticbuild watch mydemo.ticbuild.jsonc --mode debug
  ticbuild watch --hide-trace-containing "my.token"
  ticbuild watch --hide-trace-matching "reg.*ex"
  ticbuild watch --on-connect  "ping" --on-connect 'event_subscribe "cart_run|lua_profiler_stopped" 0'
