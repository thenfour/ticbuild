
ticbuild terminal

usage: ticbuild terminal [options] [host:port]

Connect to the TIC-80 remoting terminal server.

If host:port is omitted:

  - with 0 discovered running sessions, exits immediately
  - with 1 discovered running session, connects automatically
  - with multiple sessions, shows a list and prompts for selection

In terminal mode, you type commands one line at a time. Request IDs are optional.
Example:

> 0 hello
0 OK "TIC-80 remoting v1"
> hello
1 OK "TIC-80 remoting v1"

Options:

  --hide-trace-containing <text> Hide trace events whose payload contains text.
  --hide-trace-matching <regex>  Hide trace events whose payload matches a JavaScript regex.
  --on-connect <command> Send a required remoting command after connecting.
                         Repeat for multiple commands.

Examples:

  ticbuild terminal --hide-trace-containing "my.token"
  ticbuild terminal --hide-trace-matching "reg.*ex"
